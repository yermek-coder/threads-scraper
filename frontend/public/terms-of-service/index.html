Правила использования панели мониторинга упоминаний в Threads.

Сервис

Threads Brand Monitoring — закрытая панель Example Organization для поиска заданных администратором фраз в публичных публикациях Threads и отправки уведомлений выбранным получателям.

Доступ и обязанности пользователя

Доступ предоставляется авторизованным пользователям. Вы отвечаете за сохранность учётных данных, законность поисковых запросов и адресов получателей, а также за полномочия, необходимые для подключения Threads API и каналов уведомлений. Не используйте сервис для нарушения закона, прав других лиц или правил Meta, Threads, электронной почты и WhatsApp.

Данные Threads и уведомления

Публикации и материалы авторов остаются собственностью их правообладателей. Сервис показывает полученные через API данные для мониторинга и не гарантирует полноту, актуальность или доступность публикаций. Администратор отвечает за выбранных получателей и содержание отправляемых им уведомлений.

Доступность и изменения

Работа сервиса зависит от доступности сети, API Meta/Threads и сторонних каналов доставки. Example Organization может обновлять функции и эти условия; актуальная редакция публикуется на этой странице. Пользуясь панелью, пользователь принимает опубликованные условия.
