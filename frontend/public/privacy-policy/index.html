Политика конфиденциальности

Здесь описано, какие данные обрабатывает Threads Brand Monitoring и для чего они нужны.

Последнее обновление: 26 сентября 2026 года

Оператор и связь

Оператор сервиса — Example Organization. По вопросам обработки данных или реализации ваших прав напишите на info@example.com.

Какие данные обрабатываются

  • данные учётной записи панели: имя пользователя и защищённый хеш пароля;
  • заданные администратором поисковые фразы и стоп-слова;
  • публичные публикации Threads, найденные по поисковым фразам: текст, имя автора, ссылка, дата публикации и доступные счётчики взаимодействий;
  • технические данные подключения Threads API и настройки интеграций;
  • адреса электронной почты, номера WhatsApp и журналы доставки уведомлений, если администратор добавил их в настройки;
  • данные авторизованной сессии в браузере и технические журналы, необходимые для защиты и работы сервиса.

Зачем и на каком основании

Данные используются для поиска и просмотра публичных упоминаний, фильтрации публикаций, доставки выбранных уведомлений и обеспечения безопасности панели. Публикации Threads получаются через API Meta/Threads на основании настроек и разрешений подключённого администратора. Контактные данные получателей вводятся администратором сервиса.

Поставщики услуг и передача данных

Для работы сервиса данные могут обрабатываться поставщиками инфраструктуры и каналов доставки: Oracle Cloud Infrastructure для размещения сервера, Meta Platforms для API Threads, Hostinger для отправки электронной почты и WhatsApp для доставки сообщений при включённой интеграции. Эти поставщики получают только данные, необходимые для предоставления соответствующей услуги, и обрабатывают их по своим правилам.

Хранение и защита

Данные хранятся, пока это необходимо для работы мониторинга, и удаляются по запросу. Сервис использует HTTPS для передачи данных и ограничивает доступ к панели учётной записью администратора. Пароль панели хранится в виде криптографического хеша; токены интеграций используются для подключения API и не показываются в интерфейсе после сохранения.

Браузерное хранилище

Для поддержания входа браузер сохраняет технический токен авторизации в localStorage. Сервис не использует рекламные или аналитические cookies.

Ваши запросы

Вы можете запросить доступ, исправление или удаление данных по адресу info@example.com. Подробные инструкции доступны на странице удаления данных.
